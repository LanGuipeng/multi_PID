# Method and API

The engine evaluates the Shannon version of the Mages–Anastasiadi–Rohner decomposition for a finite joint distribution. It keeps the original redundancy functional and lattice; the query-specific decision representation determines which channels and integrals to compute.

## Inputs and query conventions

A `Distribution` maps states `(T, X1, ..., Xn)` to exact probabilities. Source and target values must be hashable. Probability inputs must be nonnegative and sum exactly to one. Use integers, rational strings, or `fractions.Fraction`; native float probabilities require an explicit conversion policy because their exact representation is otherwise ambiguous.

```python
from fractions import Fraction
from mar_certified import Distribution, query

P = Distribution({(0, 0, 0): Fraction(1, 2), (1, 1, 1): Fraction(1, 2)})
result = query(P, [[1], [2]], tol="1e-12")
assert result["interval"].lower == result["interval"].upper == 1
```

For count data, `Distribution(table, kind="counts")` divides nonnegative integer counts by their total exactly. The resulting certificate concerns this normalized count table.

An antichain is a nonempty family of nonempty source subsets with no inclusion between distinct members:

| Python value | Observation conditions |
|---|---|
| `[[1], [2]]` | Source 1 and source 2 separately |
| `[[1, 2]]` | Their joint observation |
| `[[1], [2, 3]]` | Source 1 and the joint observation of sources 2 and 3 |

The public API accepts these lists of one-based source indices. Internally, subsets use bit masks: `1 = {1}`, `2 = {2}`, `3 = {1,2}`, `4 = {3}`. A tuple of integers is interpreted as bit masks, so `(1, 6)` corresponds to `[[1], [2, 3]]`. Prefer lists in user-facing code.

The `query` options include:

| Argument | Meaning |
|---|---|
| `kind="atom"` | The Möbius atom at the query antichain |
| `kind="cumulative"` | Cumulative MAR redundancy |
| `method="exact"` | Exact affine segmentation followed by rational-log certification |
| `method="endpoint"` | Endpoint bounds and global dyadic refinement |
| `method="reference"` | Geometric cumulative values and complete lattice inversion for small systems |
| `method="float"` | Floating evaluation of the exact expression, without a certificate |
| `tol="1e-12"` | Requested absolute interval width in bits |
| `max_seconds`, `max_cells` | Resource limits; cell limits apply to endpoint refinement |

## Binary decision tasks

For target category $t$, let $p_t=P(T=t)$ and define the binary experiment

$$
a_x=P(X_A=x\mid T=t),\qquad b_x=P(X_A=x\mid T\ne t).
$$

The complement distribution mixes the other target categories using their conditional priors. No source independence is assumed. The payoff improvement over acting without an observation is

$$
h_{A,t}(\lambda)=\sum_x[a_x-\lambda b_x]_+-(1-\lambda)_+.
$$

The prior-dependent Shannon weight is

$$
w_p(\lambda)=\frac{(1-p)^2}{(\ln 2)\lambda(p\lambda+1-p)^2}.
$$

The query is a weighted integral of its task envelope, with the outside factor $p_t$ retained:

$$
Q_\alpha=\sum_{t:0<p_t<1}p_t\int_0^\infty w_{p_t}(\lambda)f_{\alpha,t}(\lambda)\,d\lambda.
$$

Zero-mass categories are omitted before conditioning. A constant target returns zero. Observation columns with $b_x=0<a_x$ remain part of the curve and its constant tail.

## Query envelopes and boundaries

For cumulative redundancy,

$$
f_{\alpha,t}(\lambda)=\min_{A\in\alpha}h_{A,t}(\lambda).
$$

An atom additionally uses $C_\alpha$, the inclusion-maximal nonempty source subsets that contain no member of $\alpha$:

$$
f_{\alpha,t}(\lambda)=\left[\min_{A\in\alpha}h_{A,t}(\lambda)-\max_{B\in C_\alpha}h_{B,t}(\lambda)\right]_+.
$$

The maximum over an empty boundary is zero. The boundary is a family of source subsets, rather than immediate predecessors in the redundancy lattice. For three sources and `alpha=[[1],[2,3]]`, it is `[[2],[3]]`; for four sources and the same query, it is `[[2,4],[3,4]]`.

This nonnegative envelope measures the length of the payoff-threshold interval whose upper set is generated by the requested antichain. Integrating it gives the same atom as full Möbius inversion. The engine can therefore construct the requested output without computing every cumulative lattice value.

## Exact integration and certification

`piecewise.py` forms a rational partition using positive finite likelihood ratios, the normalized cost `1`, and relevant intersections. Exact comparisons select the minimum, maximum, and positive-part branches. Each resulting piece is affine.

`exact.py` integrates these pieces and checks cancellation of the rational endpoint terms. The result is a finite expression

$$
E=\sum_j c_j\log_2 r_j,\qquad c_j\in\mathbb{Q},\quad r_j\in\mathbb{Q}_{>0}.
$$

`intervals.py` encloses each logarithm by normalizing its argument with a power of two and applying the rational series

$$
\ln v=2\sum_{j=0}^{N-1}\frac{z^{2j+1}}{2j+1}+R_N,\qquad z=\frac{v-1}{v+1},\quad 1\le v<2,
$$

with

$$
0\le R_N\le\frac{2z^{2N+1}}{(2N+1)(1-z^2)}.
$$

Interval division also accounts for the uncertainty in $\ln 2$. Negative expression coefficients reverse the interval endpoints. The series order increases until the actual rational width meets the requested tolerance.

Exact geometry and numerical certification are separate steps. A naive float evaluation of the final logarithmic expression can still cancel; use the returned rational interval for certified claims.

## Endpoint refinement

`endpoint.py` uses that each payoff curve is nondecreasing below `1` and nonincreasing above `1`. On cells that do not cross `1`, endpoint values bound each channel curve and hence the query envelope. Certified weight integrals multiply these bounds. A universal bound accounts for the omitted tails.

The implementation follows the global dyadic refinement schedule from the manuscript. It intersects completed-round enclosures and uses outward dyadic rounding for accumulation. Output records distinguish four allowances: tail truncation, envelope variation, weight arithmetic, and summation rounding. Their sum can exceed the final intersected width.

The method avoids intersection enumeration. Its measured costs in the reference examples are dominated by tail and envelope allowances; known compact atom support is not used as an extra shortcut.

## Reading a result

Successful certified results satisfy

```python
interval = result["interval"]
assert interval.width <= result["tolerance"]
assert result["tolerance_met"]
```

`exact_zero` records a structural zero certificate. A small interval containing zero does not establish exact equality. A positive lower endpoint certifies strict positivity.

When a resource limit is reached, the endpoint method can retain a valid, wider interval. Such a result has `tolerance_met=False`; a query can also terminate without an interval if its exact computation was interrupted. The CLI signals an incomplete query with a nonzero exit code. The experiment runner retains these records so that computational limits remain visible in the benchmark results.

## Independent checks

`reference.py` constructs cumulative MAR expressions through zonogon geometry and then applies the full lattice recurrence. `verification.py` compares these results with direct atom integrals and reconstructs every nonempty-subset mutual information. The small complete systems provide a check on the queried functional, not just its numerical implementation.

The experiment modules additionally use exact prime-log identities where feasible, analytic entropy formulas, and high-precision numerical quadrature. Floating reference values are independent checks; the certificates themselves come from rational interval arithmetic.
